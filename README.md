# ระบบจัดตารางเรียนอัตโนมัติ

**Automated Timetable Management System**

เว็บแอปพลิเคชันสำหรับบริหารจัดการและสร้างตารางเรียนอัตโนมัติ ช่วยลดความซ้ำซ้อนในการจัดตาราง พร้อมตรวจสอบความขัดแย้งของข้อมูลก่อนนำตารางไปใช้งาน

## คุณสมบัติหลัก

- จัดการข้อมูลครูผู้สอน รายวิชา ห้องเรียน และกลุ่มเรียน
- กำหนดวันเรียนและช่วงเวลาเรียน
- สร้างตารางเรียนอัตโนมัติ
- ตรวจสอบความขัดแย้งของตารางเรียนและการใช้ห้อง
- กำหนดคาบเรียนที่ต้องการล็อกไว้ล่วงหน้า
- แสดงตารางเรียนและตารางสอน
- นำเข้าและส่งออกข้อมูล
- พิมพ์ตารางเรียน

## การติดตั้งและเริ่มใช้งาน

### 1. ดาวน์โหลด Source Code

```bash
git clone https://github.com/auto06537-cmd/automated-timetable-management-system.git
cd automated-timetable-management-system
```

### 2. ติดตั้ง Dependencies

```bash
npm install
```

### 3. ตั้งค่า Environment Variables

คัดลอก `.env.example` เป็น `.env` และกำหนดค่าที่จำเป็นให้เหมาะสมกับเครื่องของคุณ

ห้ามเผยแพร่ไฟล์ `.env` หรือข้อมูลลับลง Repository

### 4. เตรียมฐานข้อมูล

```bash
npx prisma migrate deploy
npx prisma generate
```

### 5. เริ่มเซิร์ฟเวอร์

```bash
npm run dev
```

เปิดเว็บไซต์ที่ http://localhost:3000
